# Get help with ParrotVoice

Use **[ParrotVoice Firmware](https://github.com/ParrotVoiceApp/firmware)** for all firmware, browser bridge, pairing, call, and Console feedback. You do not need to identify the responsible component first.

- [Quickstart](https://parrotvoice.app/docs/quickstart/) — set up your board and make a first call.
- [Board and firmware](https://parrotvoice.app/docs/board-firmware/) — hardware selection, Bluetooth pairing, and firmware updates.
- [Bridge error codes](https://parrotvoice.app/docs/bridge-errors/) — understand a `PB-…` error and collect diagnostics.
- [Report a bug](https://github.com/ParrotVoiceApp/firmware/issues/1) — reproduction steps and environment details help us investigate.
- [Suggest an improvement](https://github.com/ParrotVoiceApp/firmware/issues/new/choose) — describe the problem you want to solve and the outcome you need.
- [Open-source vote](https://github.com/ParrotVoiceApp/firmware/issues/2) — react with 👍 to express interest in a source release.

Search existing reports before opening a new one. If you found the same problem, add useful details to that report. Please remove credentials, phone numbers, recordings, and other private information from anything you share publicly.

English and 中文 are both welcome. Source code is not currently published; this community space is for feedback, documentation, and open-source interest.
