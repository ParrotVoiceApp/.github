# Your voice agent. Your phone number.

**ParrotVoice connects voice agents to calls through your own phone lines.**

[Visit ParrotVoice](https://parrotvoice.app) · [Get started](https://parrotvoice.app/bridge/) · [Read the docs](https://parrotvoice.app/docs/) · [Public roadmap](https://github.com/orgs/ParrotVoiceApp/projects/1)

## Product trackers

Choose the repository for the product you use. Each tracker collects public feedback and planned improvements.

| Repository                                                               | Responsibility                                                       |
| ------------------------------------------------------------------------ | -------------------------------------------------------------------- |
| [Parrot Protocol](https://github.com/ParrotVoiceApp/ParrotProtocol)      | Connection protocol, Bridge integrations and embedded device support |
| [Firmware](https://github.com/ParrotVoiceApp/Firmware)                   | ESP32 firmware, Bluetooth and phone compatibility                    |
| [Parrot Service](https://github.com/ParrotVoiceApp/ParrotService)        | Cloud calling, accounts, devices, Console and Web Phone              |
| [Parrot Windows App](https://github.com/ParrotVoiceApp/ParrotWindowsApp) | Windows setup, updates and desktop experience                        |
| [Parrot Docs](https://github.com/ParrotVoiceApp/ParrotDocs)              | User guides, troubleshooting and documentation feedback              |
| [Parrot MCP](https://github.com/ParrotVoiceApp/ParrotMCP)                | Agent integrations, skills and marketplace availability              |
| [Firmware Flasher](https://github.com/ParrotVoiceApp/FirmwareFlasher)    | Firmware installation, updates and recovery                          |

## Current work

[Parrot Protocol](https://github.com/ParrotVoiceApp/ParrotProtocol) is being prepared for an open-source release, and support for different embedded devices is in development. Product source code is not currently published in these trackers; supported devices and availability will be announced as they are ready.

English and 中文 feedback are welcome. If you are unsure where to report a problem, use the [feedback guide](https://github.com/ParrotVoiceApp/Firmware/issues/1).
